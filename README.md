# Двойник — синтетические клиенты для тестирования банковских продуктов

**Команда MISIS X** · Академия Финтеха 2026, трек «Финтех без границ» (ВТБ)
Никита Мещеряков (ML/LLM) · Юлия Соколова (Product Manager)

Банк проверяет новый тариф, экран или коммуникацию на популяции LLM-двойников клиентов до запуска.
За минуты — прогноз конверсии по сегментам, причины отказов и цитаты «клиентов».
Двойник не заменяет A/B-тест, а отсекает слабые гипотезы до него.

## Что умеет MVP
- **7 сегментов** двойников: студенты Москвы и регионов, подростки, молодые семьи, пенсионеры, самозанятые, нерезиденты.
- **7 сценариев** по 3 варианта: студенческая карта, семейный счёт, кредитная карта, вклад для пенсионеров,
  пуш-уведомление о кэшбэке, тариф для самозанятых, переводы для нерезидентов.
  Новый сценарий — словарь в `dvoinik/scenarios.py`, без изменения кода.

| Сценарий | Что проверяем |
|---|---|
| Студенческая карта | Кэшбэк в любимых категориях, отсутствие платы или геймификация накоплений: что сильнее для студентов Москвы и регионов, подростков и иностранных студентов |
| Семейный счёт | Баланс прозрачности и приватности трат в семье и готовность платить за семейную подписку |
| Кредитная карта | Как подать льготный период молодым клиентам: «дни без процентов», рассрочка с напоминанием или большой лимит |
| Вклад для пенсионеров | Какой канал открытия вызывает доверие у клиентов 60+ и повышает ли его встроенная защита от мошенников |
| Пуш о кэшбэке | Текст коммуникации до рассылки: срочность, персональная выгода в рублях или выбор категорий; риск восприятия как спама |
| Тариф для самозанятых | За что платит предприниматель: бесплатный счёт с комиссией, прогноз кассовых разрывов или автоотложение на налоги |
| Переводы для нерезидентов | Что важнее для подключения: комиссия, многоязычный интерфейс, помощь с документами или AI-помощник на родном языке |

- **Отчёт**: конверсия по вариантам и сегментам, причины отказа, голоса двойников.
- **Валидация**: сравнение с опросом живых респондентов (MAE конверсии, Spearman по ранжированию вариантов, совпадение победителя).
- **On-prem**: любая OpenAI-совместимая модель (vLLM/Ollama с open-weight моделями, российские модели через шлюз).
  В симуляции нет персональных данных клиентов.

## Запуск
```bash
pip install -r requirements.txt

# демо без LLM
DVOINIK_MOCK=1 streamlit run app.py
python cli.py student_card --n 500 --mock

# с локальной моделью
ollama pull qwen2.5:7b-instruct
LLM_BASE_URL=http://localhost:11434/v1 LLM_MODEL=qwen2.5:7b-instruct streamlit run app.py
```

## Архитектура
```
dvoinik/population.py  сегменты и генерация двойников (калибровка на открытой статистике)
dvoinik/scenarios.py   сценарии: варианты продукта, вопрос, категории отказа
dvoinik/engine.py      симуляция: LLM (async) или эвристический режим; агрегация отчёта
dvoinik/validate.py    сравнение прогноза с живым опросом
app.py / cli.py        интерфейсы
```

## Дорожная карта
- Спринт 1: калибровка сегментов на открытых данных, валидация на опросе 30+ респондентов.
- Спринт 2: тест экранов по скриншоту (VLM), финмодель, развёртывание on-prem.
- Спринт 3: ретро-тест на прошлом запуске с известным результатом, сценарий пилота.

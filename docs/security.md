# Двойник в контуре банка

Двойник рассчитан на работу внутри периметра банка: тексты будущих предложений и результаты
исследований не уходят к внешним поставщикам. Ниже — что именно это гарантирует и чем подтверждено.

## Какие данные куда идут

| Данные | Где хранятся | Куда передаются |
| --- | --- | --- |
| Тексты предложений, вопрос, сегменты | SQLite-архив на томе сервиса (`DVOINIK_STORAGE_PATH`) | Только в модель по `LLM_BASE_URL` |
| Синтетические профили | Генерируются в памяти, до трёх на сегмент сохраняются в снимке | Только в модель по `LLM_BASE_URL` |
| Ответы модели | Снимок исследования; по желанию — кэш `DVOINIK_LLM_CACHE_PATH` | Никуда |
| Ответы живого опроса (CSV) | Снимок исследования после подтверждения | Никуда |
| Аккаунты | Тот же SQLite, пароли — Argon2 | Никуда |

Персональные данные клиентов банка Двойнику не нужны: профили синтетические, сегменты задаются
долями. Если банк захочет обогатить профили своими агрегатами, это делается обезличенными
долями на этапе пилота.

## Чем подтверждено

- **Сервис ходит только в модель.** Тест `tests/test_no_egress.py` записывает все сетевые
  соединения процесса: демо-запуск и отчёт не открывают ни одного, LLM-режим подключается
  только к адресу из `LLM_BASE_URL`.
- **Браузер ходит только в сервис.** Каждый ответ несёт Content-Security-Policy
  `default-src 'self'; connect-src 'self'; script-src 'self'`: внешние скрипты, шрифты и запросы
  браузер заблокирует. Интерфейс не использует CDN и внешние шрифты.
- **Работает без сети.** CI собирает Docker-образ и запускает симуляцию в контейнере с
  `--network none`, затем поднимает сервис и проверяет заголовок CSP.
- **Доступ.** Локальные аккаунты и роли, HttpOnly-сессии с защитой от CSRF, архивы владельцев
  разделены, скачивания — одноразовые ссылки с белым списком форматов.

## Развёртывание

```bash
docker compose up -d
docker compose exec ollama ollama pull qwen2.5:7b-instruct
docker compose exec ollama ollama pull bge-m3      # для режима SSR
docker compose exec app python manage.py create-user --username analyst --name "Аналитик"
```

`docker-compose.yml` поднимает сервис и локальную модель в Ollama. Порт модели наружу не
публикуется, интерфейс слушает только `127.0.0.1:8501` хоста — дальше его закрывает
балансировщик банка. Вместо Ollama можно указать любой OpenAI-совместимый сервер в контуре
(vLLM, шлюз к GigaChat или YandexGPT в закрытом исполнении).

## Что пока не сделано

- Корпоративный SSO (LDAP, Keycloak) — этап пилота; сейчас локальные аккаунты.
- Журнал аудита действий пользователей — этап пилота.
- Шифрование архива на диске — средствами тома или СУБД банка.

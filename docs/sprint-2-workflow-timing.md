# Хронометраж подготовки исследования

Этот замер проверяет тезис из Q&A MISIS X об экономии времени и себестоимости. Единица сравнения — один план, который можно передать другому исследователю для запуска. Время работы модели и время человека записываются отдельно.

1. Дайте двум участникам два близких задания: проверить канал открытия вклада для аудитории 60+ и проверить, меняет ли упоминание дополнительной защиты интерес к вкладу при тех же условиях. Каждый участник делает один план обычным способом, другой с «Двойником». Первый участник делает задание A обычным способом, B с «Двойником». Второй делает A с «Двойником», B обычным способом. Используйте одинаковые исходные материалы и обычные для команды инструменты в ручном варианте. Не показывайте готовый результат до замера.
2. Старт — участник открыл задание. Стоп — план передан на проверку. Если рецензент возвращает его, прибавьте активное время проверки и доработок. Отдельно отметьте ожидание, когда исследователь мог переключиться на другую работу, и когда был заблокирован. Первый вход, настройку и обучение фиксируйте отдельно от повторяемой подготовки.
3. Рецензент по возможности не знает, каким способом сделан план. По одному баллу за каждый пункт: ясная гипотеза, варианты отличаются одним фактором, указаны аудитория и метрика, описано решение при неопределённом результате. Сравниваем минуты после доведения обоих планов до одного уровня. Если задания различались по трудности или что-то осталось незавершённым, сохраняем это как оговорку.
4. Трудозатраты = активные минуты / 60 × стоимость часа. Добавьте прямые затраты запуска, если они измерены по счёту или тарифу. При отсутствии тарифа покажите расход токенов отдельно. Повторные сравнения на коллегах — внутренняя репетиция. Банковский ROI требует замера у банковской команды и подтверждения числа исследований в месяц.

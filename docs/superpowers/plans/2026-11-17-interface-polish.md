# Цельный интерфейс исследования — Implementation Plan

**Goal:** Реализовать одобренные пользователем шесть направлений: архив, краткий итог отчёта, типографика, конструктор, мобильные действия, обратная связь.
**Architecture:** Продолжить существующую React/CSS систему и градиентные токены. Данные и API сохраняются; новые представления используют только текущий снимок/черновик. Архив и конструктор выполняют отдельные агенты, основной агент собирает отчёт и общие стили.
**Tech Stack:** React, TypeScript, CSS, Vitest, Testing Library.
**Spec:** Обсуждение с пользователем от 17 ноября: все шесть предложенных улучшений одобрены командой «давай сделаем тогда все это»; базовые истории — ../specs/2026-11-15-user-journeys-design.md.

## Ограничения

Сохраняем индиго/синий/бирюзовый стиль, существующие поля и доступность. Критические предупреждения видны рядом с результатом. Демонстрация/симуляция не становится прогнозом спроса. Без новых внешних шрифтов/трекеров. Движение отключается при prefers-reduced-motion.

## Review Focus

- Состояния загрузки/ошибки/отсутствия валидных ответов различимы.
- Родитель итерации может отсутствовать в архиве; поиск/пагинация не теряют записи.
- Предпросмотр аудитории может быть устаревшим: проценты не показываются как актуальные.
- Сохранение опроса может завершиться ошибкой: успех объявляется только после ответа.
- Мобильная панель не закрывает поля/кнопки и учитывает нижнюю навигацию.

# Управление запусками

Пользователь продолжает комплексное улучшение MVP для банковских продуктовых команд. Эта итерация делает существующий запуск управляемым: уход на другую страницу и обновление браузера не скрывают выполняющееся исследование. Учётная запись nikita, пароль и личный архив сохраняются.

## Контракт

Jobs остаётся ограниченным исполнителем в одном процессе. GET /api/runs возвращает только активные queued/running/cancelling задачи исходной cookie-сессии, без обновления таймера бездействия. POST /api/runs/{id}/cancel защищён существующим CSRF и правами исходной сессии. Повторная остановка идемпотентна; завершённый результат не удаляется.

Очередь отменяется через Future.cancel. Работающая задача переходит в cancelling, затем cancelled после возврата уже начатого запроса и проверки guard. Guard запрещает новые оценки и запись частичного результата. Слот и ограничение одного запуска на владельца освобождаются только при фактическом завершении работника; активный отменяемый запуск нельзя вытеснить из retained-кэша. Остановка сервиса остаётся failed с прежним сообщением.

## Интерфейс

Хук текущего запуска опрашивает сервер независимо от маршрута и обнаруживает запуск после перезагрузки. Компактная полоса вне страницы симуляции ведёт к запуску. Завершение в фоне обновляет архив, сохраняя текущий маршрут; переход к отчёту происходит только на странице запуска. Ошибка опроса не превращает действующую задачу в провалившуюся; доступно повторное чтение. На странице запуска есть остановка, состояние ожидания остановки и возврат после cancelled. Повторный запуск при активной задаче ведёт к ней.

## Границы

Без новых runtime-зависимостей, без внешнего брокера и постоянной очереди. Перезапуск процесса не возобновляет LLM-работу. В интерфейс и Git не попадают токены, пароль и реальный архив. QA использует отдельную SQLite и localhost; основной сервис остаётся 127.0.0.1:8501. Node 24.15+, Python 3.11+. Демоданные не называются проверенными прогнозами.

## Проверка

Реальная очередь с заблокированным работником: queued отменяется сразу, running удерживает слот, после отмены нет снимка. Реальный движок с подменённым внешним LLM-транспортом: следующая оценка не отправляется. HTTP: чужая сессия/CSRF, идемпотентность, сохранённый результат, idle TTL. React: обнаружение после reload, завершение в фоне, восстановление после ошибки и отсутствие позднего callback после unmount. Браузер: навигация, остановка, адаптивность; весь существующий набор проверок.

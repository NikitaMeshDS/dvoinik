# Пример MVP

[senior-deposit.demo.json](senior-deposit.demo.json) — полный экспорт демонстрационной
симуляции из текущего CLI: 200 синтетических профилей аудитории 60+, три предложения,
seed 42, `mock: true`. Варианты и объяснения вымышлены; опроса живых респондентов нет.
Это пример формата и рабочего процесса, а не доказательство конверсии банковских клиентов.

Создан командой:

```bash
python cli.py senior_deposit --n 200 --mock --seed 42 --output examples/senior-deposit.demo.json
```

Импортируйте файл через страницу «Исследования». При импорте создаётся новый ID текущего
пользователя; исходный ID сохраняется как происхождение. Никаких аккаунтов, ключей доступа,
банковских персональных данных или токенов скачивания в примере нет.

В новом запуске ID, время и длительность отличаются. При одинаковой версии кода, сценарии
и seed профили и демо-ответы воспроизводятся.
